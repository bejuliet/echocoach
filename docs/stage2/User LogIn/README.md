This folder is the single Login-module documentation set. It covers login to existing Coach and Admin accounts, secure session restoration and logout integration. Role is resolved automatically from authenticated identity. **It does not design Account Initialization or Account Management**.

- `EchoCoach_Stage2_User_Login_Implementation_v1.0.md` — implementation-ready checklist and unresolved authentication-provider/schema decisions; not coding approval.
